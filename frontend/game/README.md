
# 坦克大战游戏

一个使用面向对象JavaScript开发的经典坦克大战游戏。

## 游戏特性

### 核心功能
- **面向对象设计**: 使用ES6类构建，代码结构清晰
- **流畅的游戏体验**: 60FPS游戏循环，平滑的动画效果
- **智能AI敌人**: 敌人坦克具有基本AI，会自动移动和射击
- **碰撞检测**: 精确的矩形碰撞检测系统
- **关卡系统**: 多关卡设计，难度递增

### 游戏元素
- **玩家坦克**: 绿色坦克，可通过键盘控制
- **敌人坦克**: 红色坦克，AI自动控制
- **地图系统**: 随机生成的障碍物和墙壁
- **子弹系统**: 支持多发子弹，不同颜色区分敌我
- **特效系统**: 爆炸效果和粒子特效

### 障碍物类型
- **砖墙**: 橙色，可被子弹摧毁
- **钢墙**: 灰色，不可摧毁，通常作为边界
- **草地**: 绿色，可通过但会遮挡视线

## 游戏控制

### 键盘控制
- **W / ↑**: 向上移动
- **A / ←**: 向左移动  
- **S / ↓**: 向下移动
- **D / →**: 向右移动
- **空格键**: 发射子弹
- **R键**: 重新开始游戏

## 技术架构

### 核心类结构

```
GameEngine          # 游戏引擎 - 负责游戏循环和渲染
├── TankGame        # 主游戏类 - 游戏逻辑控制
├── GameMap         # 地图系统 - 地图生成和碰撞检测
├── Tank            # 坦克基类
│   ├── PlayerTank  # 玩家坦克
│   └── EnemyTank   # 敌人坦克
├── BulletManager   # 子弹管理器
├── Bullet          # 子弹类
└── 工具类
    ├── Vector2D           # 二维向量
    ├── CollisionDetector  # 碰撞检测
    └── InputManager       # 输入管理
```

### 设计模式
- **组合模式**: 游戏对象组合管理
- **策略模式**: 不同类型坦克的行为策略
- **观察者模式**: 事件驱动的输入处理
- **工厂模式**: 敌人和子弹的创建

## 游戏规则

### 获胜条件
- 消灭指定数量的敌人坦克即可进入下一关
- 每关敌人数量递增，AI难度提升

### 失败条件
- 玩家坦克生命值归零

### 计分系统
- 击败敌人获得分数
- 敌人难度越高，获得分数越多
- 完成关卡有额外奖励

## 如何运行

1. 确保所有文件都在同一目录下
2. 使用现代浏览器打开 `index.html`
3. 开始游戏！

## 浏览器兼容性

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

支持所有现代浏览器，需要ES6支持。

## 扩展功能建议

### 可添加的功能
- **道具系统**: 加血包、武器升级等
- **音效系统**: 射击、爆炸、背景音乐

## 开发说明

这个游戏完全使用原生JavaScript开发，没有使用任何外部库。代码采用面向对象的设计，易于理解和扩展。每个类都有明确的职责，遵循单一职责原则。

游戏使用Canvas 2D API进行渲染，requestAnimationFrame实现流畅的动画效果。所有的游戏逻辑都是基于时间的，确保在不同帧率下游戏速度一致。
