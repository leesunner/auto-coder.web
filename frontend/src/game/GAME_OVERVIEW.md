## 🎯 核心特性

### 1. 面向对象设计
- **完全面向对象架构**：每个游戏元素都是独立的类
- **清晰的职责分离**：渲染、输入、碰撞检测等都有专门的类
- **继承关系**：Enemy继承自Tank，展示了OOP的继承特性
- **封装性**：私有方法和属性的合理使用

### 2. 智能AI系统
- **三种AI状态**：巡逻、追击、攻击
- **动态行为切换**：根据与玩家的距离自动切换行为
- **智能寻路**：敌人能够追踪和攻击玩家

### 3. 完整的游戏机制
- **实时碰撞检测**：AABB算法实现精确碰撞
- **射击系统**：冷却时间、弹道计算
- **生命值系统**：血条显示、伤害计算
- **关卡系统**：消灭敌人进入下一关
- **得分系统**：击败敌人获得分数

### 4. 现代Web技术
- **TypeScript**：类型安全的开发体验
- **HTML5 Canvas**：高性能的2D渲染
- **React集成**：可以作为React组件使用
- **响应式设计**：支持不同屏幕尺寸
