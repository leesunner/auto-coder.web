📋 测试建议

功能测试

  1. 启动前端开发服务器
  2. 导航到包含 TerminalOutput 组件的页面
  3. 切换到 "terminal" 标签页
  4. 查看是否显示带下拉箭头的加号按钮
  5. 鼠标悬停在按钮上，检查下拉菜单是否出现
  6. 点击不同的 shell 选项，检查控制台日志

边界测试

  1. 切换到 "output" 标签页，确认按钮隐藏
  2. 在不同屏幕尺寸下测试响应式布局
  3. 测试国际化切换
